# 修复日报自动化超时

## 背景

日报自动化在执行 Playwright CLI 时只向用户报告通用超时，无法确定卡在会话检查、浏览器启动、页面填报还是提交阶段。多个入口还可能同时访问同一个浏览器 Profile，导致会话冲突或残留会话后的失败难以复盘。

## 变更

- 串行化日报登录、填报和提交的 Playwright CLI 操作，避免共享浏览器 Profile 并发访问。
- 为每个 CLI 阶段附加明确名称，并在超时错误中提供会话、命令、进程号、时限及有限诊断输出。
- 超时或调用取消时终止本次 CLI 的完整进程树并等待短暂退出。
- 保留主操作异常；会话清理失败仅作为附加诊断，不覆盖填报/提交失败原因。
- 为阶段时限、取消语义和清理异常补充自动化测试。

## 验收

1. 同一运行时内的日报浏览器操作不会并发执行。
2. 超时错误能显示发生阶段，并提示完成登录或查看该阶段的诊断。
3. 用户取消不会被误报为 CLI 超时。
4. 填报或提交失败时，会话清理异常不会遮蔽原始异常。
5. 测试通过，Release 产物重新发布至 `publish`。
